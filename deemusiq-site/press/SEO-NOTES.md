# DeeMusiq — SEO Notes (internal)

State of SEO plumbing on deemusiq.co.za and what is still TODO by a human.
Last updated: 2026-09-30.

## Done (in repo)

- `index.html`: JSON-LD structured data — `Organization` + `SoftwareApplication`
  (no `aggregateRating`; add only once real ratings exist). The two inline blocks
  are CSP-protected: their sha256 hashes are pinned in `_headers` under
  `script-src`. **If you edit either JSON-LD block, recompute the hashes** (sha256
  of the exact bytes between the `<script>` tags, base64) and update `_headers`.
- `sitemap.xml`: all public pages (`/`, `/press/`, `/privacy.html`, `/terms.html`)
  with `lastmod`, `changefreq`, `priority`; `xmlns:image` with the OG image on the
  homepage entry.
- `robots.txt`: already references the sitemap.
- `.well-known/assetlinks.json`: Android App Links statement for package
  `oss.krtirtho.spotube`. **PLACEHOLDER** — see below.
- `llms.txt`: LLM-facing site summary at the site root.
- `site.webmanifest`: full icon set (32 / 180 / 192 / 256 / 512), `display: standalone`.
- `press/`: self-serve press kit linked from the footer and the sitemap.

## TODO — requires the owner

1. **Android App Links fingerprint (blocking App Links).**
   `.well-known/assetlinks.json` contains a `REPLACE_ME` placeholder for
   `sha256_cert_fingerprints`. Paste the release-keystore SHA-256 fingerprint from:

       keytool -list -v -keystore /path/to/deemusiq-release.keystore -alias <alias>

   (If Play App Signing is used, take the "App signing certificate" fingerprint
   from Play Console instead.) Full instructions: `.well-known/assetlinks.README.txt`.

2. **IndexNow key file — deliberately NOT committed.**
   Do not let anyone commit a fabricated IndexNow key. To enable IndexNow instant
   indexing (Bing/Yandex):
   1. Generate a UUID: `python3 -c "import uuid; print(uuid.uuid4())"` (or `uuidgen`).
   2. Create `<uuid>.txt` at the site root containing exactly that UUID (no newline issues).
   3. Submit URLs to `https://api.indexnow.org/indexnow` with `key=<uuid>` and
      `keyLocation=https://deemusiq.co.za/<uuid>.txt` whenever pages change.
   The key file is per-site secret-ish and must be generated by the owner, not invented.

3. **Search Console / Bing Webmaster Tools verification.** Add the verification
   meta tag or DNS record once accounts exist, then submit `sitemap.xml`.

4. **Social `sameAs`.** The Organization JSON-LD ships with `"sameAs": []`. Once the
   official profiles are confirmed (Facebook/Instagram/TikTok/YouTube/X links are in
   the site footer), add the canonical profile URLs to that array — and recompute the
   CSP hash (see above).

5. **`aggregateRating`**: only add to the SoftwareApplication JSON-LD when there are
   genuine, verifiable user ratings. Fake ratings violate Google's structured-data
   policy and can get the whole site flagged.
